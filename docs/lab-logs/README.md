# lab-logs

**Τι είναι:** captured output από δοκίμια — ό,τι τύπωσε ένα τρέξιμο,
αυτούσιο, με f-number, αντικείμενο και ημερομηνία στο όνομα.

**Τι ΔΕΝ είναι:** πηγή αλήθειας. Η ετυμηγορία ζει στο FINDINGS ή στο
DECISIONS· εδώ ζει **το τεκμήριο** — η γραμμή που διαβάστηκε, όχι το
συμπέρασμα που βγήκε.

**Πώς γεννιέται:** με `tee` **κατευθείαν εδώ**, ποτέ σε προσωρινό
φάκελο «για να μεταφερθεί μετά». Η μεταφορά δεν έγινε ποτέ.
