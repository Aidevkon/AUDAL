================================================================================
DOM INSPECTOR FOR AI AGENT (SPECIFICATION)
================================================================================

1. ΣΚΟΠΟΣ
---------
Η δημιουργία ενός μηχανισμού που επιτρέπει στον AI Agent (Antigravity) να "βλέπει" 
την πραγματική, rendered κατάσταση του DOM (UI) σε εφαρμογές βασισμένες σε Web 
τεχνολογίες (Tauri / Dioxus), χωρίς να χρειάζεται ανθρώπινη περιγραφή της οθόνης.

2. ΤΟ ΠΡΟΒΛΗΜΑ ΠΟΥ ΛΥΝΕΙ
------------------------
- Εξαλείφει το "τυφλό" frontend debugging (CSS, layouts, missing elements).
- Επιτρέπει closed-loop αυτοματοποιημένο testing: Ο Agent εκτελεί μια αλλαγή, 
  προσομοιώνει ένα κλικ και διαβάζει το DOM για να επιβεβαιώσει το αποτέλεσμα.
- Διαβάζει το πραγματικό UI state (π.χ. data-attributes) αντί για να προσπαθεί 
  να κάνει reverse-engineer τα console logs.

3. ΑΡΧΙΤΕΚΤΟΝΙΚΗ (Πώς θα λειτουργεί)
------------------------------------
- Ο Μηχανισμός θα αποτελείται από ένα JavaScript payload (Snipppet).
- Ο Agent θα μπορεί να ζητήσει την εκτέλεση αυτού του payload.
- Στο Tauri, αυτό μπορεί να γίνει μέσω ενός "Debug RPC Command" ή αν ο Agent 
  χρησιμοποιεί browser_subagent, μέσω ενέσιμης JavaScript.
- Η JavaScript θα σαρώνει (traverse) το <body>, θα φιλτράρει τα "άχρηστα" tags, 
  και θα δημιουργεί ένα καθαρό JSON Snapshot.

4. ΤΙ ΘΑ ΠΕΡΙΕΧΕΙ ΤΟ JSON SNAPSHOT
----------------------------------
- Tree Structure: Την ιεραρχία των σημαντικών στοιχείων (divs, buttons, inputs).
- Attributes: id, class, data-* attributes, aria-labels.
- State: input values, checked states, disabled states.
- Computed Styles (προαιρετικά): Ορατότητα (display, opacity), μέγεθος (bounding box) 
  για να ξέρει ο Agent αν ένα στοιχείο κρύβεται πίσω από κάτι άλλο.

5. ΕΦΑΡΜΟΓΗ ΣΤΟ CREATOR-OS (TAURI/DIOXUS)
-----------------------------------------
- Μπορεί να ενσωματωθεί ένα ειδικό `#[tauri::command]` που κάνει `eval` τη JavaScript 
  στο WebView και γυρνάει το αποτέλεσμα πίσω στον m0-daemon ή στα logs, όπου ο 
  Agent μπορεί να το διαβάσει.
- Εναλλακτικά, μια κρυφή "συντόμευση" (π.χ. πατώντας Ctrl+Shift+D) που κάνει dump 
  το DOM JSON σε ένα αρχείο `/tmp/ui_snapshot.json` το οποίο διαβάζει ο Agent.

6. ΚΑΝΟΝΕΣ ΧΡΗΣΗΣ (NO CODE - CONCEPT ONLY)
------------------------------------------
- Η υλοποίηση θα γίνει ΜΟΝΟ όταν το αποφασίσει ο χρήστης.
- Η JavaScript πρέπει να είναι lightweight, να μην προκαλεί memory leaks 
  και να τρέχει μόνο on-demand.
================================================================================
