# AudioLabs Erlangen NMFD Golden Master Exporter

This folder contains the golden-master reference data generated by the `libnmfd` Python package (v1.0.0, MIT License). It serves as the mathematical ground truth for future Rust porting and testing.

## Files
- `export_golden.py`: The script that generates the data.
- `requirements-lock.txt`: The exact Python environment used.
- `.npy` files: The extracted spectrogram (`V.npy`), initializations, and outputs (W, H, cost functions) of both NMF and NMFD algorithms.
- `params.json`: The exact parameters and STFT conventions (including window functions and mirror reconstruction settings) used during generation.
- `fixture.wav`: A 3-second 22050Hz deterministic audio fixture containing a click train, two sine waves (440Hz and 880Hz), and 0.5s of white noise at the head.

## How to Regenerate
Ensure you have the exact Python environment by installing the dependencies from `requirements-lock.txt` into a Python 3.12 virtual environment.
Run the exporter:
```bash
python3 export_golden.py run
```
To verify determinism and view file hashes:
```bash
python3 export_golden.py hash
```

## Important Note: NMFD Init Bug
The `libnmfd` package (v1.0.0) contains a logic bug in `libnmfd.core.nmfconv.nmfd()`. If the function is called with `init_W=None` (the default), it attempts to read the shape of `init_W` on line 248 before it has actually been initialized (which happens on line 251), resulting in a `TypeError: 'NoneType' object is not subscriptable`.
**Resolution**: We completely bypass this bug by enforcing our Determinism Doctrine. We *always* explicitly generate and provide seeded matrices for `init_W` and `init_H` in the method call. For NMFD, `init_W` must be provided as a Python `List` containing `K` NumPy arrays, each of shape `(num_bins, num_template_frames)`.
